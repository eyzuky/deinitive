What you're building

memwatch is a Swift CLI that captures the iOS simulator's heap, names the snapshot, then diffs two snapshots to surface objects that didn't release. The same operations are exposed over MCP so AI coding agents can ground memory-bug debugging in real heap state instead of guessing.

You already know how to write iOS apps. These lessons fill the OS-side and tooling-side gaps the project assumes you have: how the heap is laid out at runtime, how Swift programs work outside an Xcode project, how Apple's command-line tools see into a running process, and what JSON-RPC and MCP actually are.
